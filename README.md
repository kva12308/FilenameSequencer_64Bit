# FilenameSequencer

**FilenameSequencer** is a simple desktop application that renames files in alphabetical order using sequential numbers.

## ✨ Features

- 📁 Select a folder to organize.
- 👀 Preview filenames before renaming.
- 🔢 Rename files sequentially (`1.png`, `2.pdf`, `3.jpg`, etc.).
- 📌 Preserve original file extensions.
- 📂 Only rename files in the selected folder, not files inside subfolders.
- 🖥️ Simple and beginner-friendly graphical interface.
- 🌐 English interface.

## 🚀 Getting Started

### Windows Application

1. Download `FilenameSequencer.exe` from the [Releases](../../releases) page.
2. Run `FilenameSequencer.exe`.
3. Select the folder containing the files you want to rename.
4. Review the filename preview.
5. Confirm the operation to rename your files.

### Running from Python

If you have Python installed:

1. Download or clone this repository.
2. Open the project folder.
3. Run `FilenameSequencer.pyw`.

## ⚠️ Important Notes

- Renaming files changes their filenames, not their contents.
- Check the preview carefully before confirming.
- Back up important files before renaming them.
- Files are renamed within the selected folder only; subfolders are not processed.
